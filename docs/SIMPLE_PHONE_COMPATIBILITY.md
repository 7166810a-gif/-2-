# טלפון פשוט ללא אפליקציה — דרישות תאימות

NexusLink מותקן על הנגן בלבד. הטלפון אינו צריך אפליקציה, אינטרנט או נתונים סלולריים.

## תנאי הכרחי
הטלפון הפשוט צריך לתמוך ב-Bluetooth Hands-Free Profile בתפקיד Audio Gateway (AG), כפי שקיים בטלפונים פשוטים רבים.

הנגן חייב לתמוך ב-HFP Hands-Free Unit (HF) בצד מערכת ההפעלה/קושחת Bluetooth שלו. תמיכת Bluetooth רגילה או A2DP בלבד אינה מספיקה לשיחות. באנדרואיד רגיל, אפליקציות צד שלישי אינן מקבלות API ציבורי כללי להפעלת תפקיד HFP-HF. לכן יש לבדוק את דגם הנגן ואת הקושחה לפני הבטחה של שיחות, חיוג מרחוק, מענה, DTMF וניתוב שמע.

## מה אפשר לבצע בלי אפליקציה בטלפון
- צימוד Bluetooth בהגדרות הטלפון והנגן.
- שיחות וניתוב שמע אם שני הצדדים תומכים בפרופיל HFP.
- הצגת שם/מספר מתקשר, מצב שיחה ופקודות חיוג/מענה/ניתוק אם מערכת הנגן מספקת API או שירות מערכת מתאים.

## מה אינו מובטח
- יומן שיחות ואנשי קשר דורשים תמיכת PBAP (Phone Book Access Profile) בצד הנגן ובטלפון, ולעיתים אישור שיתוף בטלפון.
- שליחת פקודות דרך RFCOMM מותאם אישית לא תעבוד עם טלפון פשוט שלא מריץ את תוכנת NexusLink.
- הקלטת שיחות תלויה במכשיר, במדיניות מערכת ובהוראות הדין; אין API ציבורי אחיד להקלטת שיחות סלולריות.
- שירות InCallService באפליקציה בנגן שולט רק בשיחות של חשבון טלפון הרשום במערכת Android המקומית. הוא אינו הופך את הנגן אוטומטית לדיבורית HFP עבור טלפון חיצוני.

## המידע הדרוש לאינטגרציה מלאה
יש לספק את דגם הנגן המדויק (כולל גרסת Android וקושחה), והאם בהגדרות Bluetooth שלו קיימת אפשרות חיבור כ"דיבורית/Hands-free" לטלפון. אם אין תמיכה HFP-HF בקושחה, נדרש עדכון יצרן או מודול Bluetooth HFP חיצוני עם ממשק פקודות ואודיו מתאים.
