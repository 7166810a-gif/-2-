# NexusLink — נגן Bluetooth לרכב

אפליקציית Android דו-מצבית: נגן (Head Unit) ומכשיר טלפון (Companion). התקשורת בין המכשירים נעשית ב-Bluetooth Classic RFCOMM בלבד, ללא שירות ענן.

## חשוב לדעת
האפליקציה מעבירה נתוני אנשי קשר, יומן שיחות ופקודות שליטה באמצעות Bluetooth. שליטה מלאה בנתיב שמע שיחה וב-HFP תלויה בתמיכת Android/יצרן בצד הנגן; אפליקציה רגילה אינה יכולה להבטיח תחליף מלא למערכת מולטימדיה מקורית. הקלטת שיחות אינה ממומשת, משום שאין API ציבורי אחיד שמאפשר הקלטת שיחות בכל מכשירי Android.

## בנייה
GitHub Actions בונה APK מסוג debug בכל push ל-main. יש להתקין את אותו APK בשני מכשירי Android: לבחור 'נגן' במכשיר הנגן ו'טלפון' במכשיר שמחזיק את ה-SIM. יש לבצע צימוד Bluetooth בהגדרות Android לפני החיבור.
